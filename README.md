# 이진호 · 데이터 엔지니어 포트폴리오

흩어진 데이터를 수집·정제하고 출처와 검증 기준을 함께 남깁니다. 생물공학 전공과 연구 경험을 바탕으로 데이터가 만들어진 조건과 해석의 한계를 살피며, 분석과 서비스에 연결하는 일을 해왔습니다.

**대표 프로젝트는 2023년 부동이입니다.** 최근 집담에서는 팀 공통 개발 기반을 구축했고, 저장소는 원본 보존·통합 DB·추천 준비 상태 관리와 CLI 하네스로 확장됐습니다.

## 기술 경험

- Python으로 API·크롤링·CSV/JSON/XLSX 처리를 수행하고 데이터 단위·날짜·결측을 확인했습니다.
- 부동이에서 주소·좌표를 기준으로 데이터를 연결하고 EDA·회귀·질의응답에 활용했습니다.
- 집담의 팀 공통 개발 규칙을 마련했습니다. 저장소에는 SQLite 데이터 모델·원본 추적·반복/증분 적재·검수 관계를 통한 읽기 전용 serving과 테스트가 있습니다.
- 모델 점수는 데이터 분할·평가 경로와 함께 설명합니다. 합성 계약검사와 실제 서비스 품질 평가는 구분합니다.
