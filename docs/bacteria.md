# 라만 분광 기반 박테리아 종 분류

2023.06.15–22 개인 프로젝트. 생물공학 배경을 바탕으로 분광 데이터의 중복·특징을 살피고 분류 모델을 비교했습니다.

## 전처리 판단

기존 자료에는 200,000행에서 123,993행으로 정리하고 파일 크기를 440MB에서 141MB로 줄인 기록이 있습니다. 중복 제거 후 각 표본의 빈도 가중치를 보존해 관측 빈도를 모델링에 반영했습니다. 파일 크기 감소를 추론속도 개선으로 해석하지 않습니다.

## 결과를 구분해 읽기

| 경로 | 기록된 정확도 |
|---|---:|
| ExtraTrees, Kaggle |95.72%|
| 스태킹, 내부 분할 |96.0039%|
| 스태킹, Kaggle 제출 |92.68%|

대표 성과는 사용자가 확인한 **ExtraTrees Kaggle95.72%**입니다. 내부 분할의 스태킹 수치를 Kaggle 성과나 교차검증 평균으로 쓰지 않습니다. 내부와 제출 점수 차이는 검증 설계를 점검해야 할 근거이며 개선 완료로 소개하지 않습니다.
