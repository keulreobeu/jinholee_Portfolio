# 비전 AI 기반 행동 탐지·자동 문서화

2025.11.12–26, 6인 팀 프로젝트. 반복 수기 기록을 영상의 행동·객체 상태·이벤트 로그로 구조화해 문서에 연결했습니다.

## 개인 기여

데이터 수집·라벨링·전처리, 시계열 윈도우 구성, 행동 모델 비교·구현, 객체 모델 학습과 통합 출력, LangChain 구성을 담당했습니다. 기획·촬영·UX/UI·대시보드 전체를 단독 성과로 설명하지 않습니다.

## 핵심 결정

이미지 시퀀스의 메모리·저장 비용을 고려해 손 랜드마크를 시계열 입력으로 구성했습니다. 행동 신호와 객체 상태(Open/Close, Full/Empty)를 구분하고 통합 출력에서 문서 생성에 필요한 이벤트를 남겼습니다.

영상·라벨 수집, 랜드마크와 윈도우 변환, 모델 출력 통합, 이벤트 로그, LangChain 문서 생성 순으로 읽을 수 있습니다. 모델 출력과 실제 업무 사건의 구간 판정은 다른 평가 대상입니다.

## 결과와 평가 조건

- 팀 수집 영상 280건,28세트. 별도 테스트 영상 10건 기록입니다.280개 독립 환경을 의미하지 않습니다.
- 기존 프로젝트 문서의 TCN F1은 0.765, Accuracy는 0.755입니다. 영상/세트 단위 분할과 융합 전후 이벤트 검출 성능을 이번에 독립 재검증하지 않았습니다.
- 문서 작성시간 절감·오류 감소는 측정값이 없어 성과 수치로 쓰지 않았습니다.
